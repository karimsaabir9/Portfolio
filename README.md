# 🌟 Modern Portfolio - Karim Sabir

Welcome to my professional portfolio! This is a modern, responsive, and high-performance web application built to showcase my skills, projects, and professional experience as a Frontend Developer.

![Portfolio Screenshot](/public/images/s.JPG)

## 🚀 Key Features

- **🌓 Dynamic Dark Mode**: Seamlessly switch between light and dark themes with a persistent UI state.
- **📱 Fully Responsive**: Optimized for all devices, from mobile phones to large desktop monitors.
- **✨ Smooth Animations**: Powered by Framer Motion for a premium user experience and interactive transitions.
- **📂 Project Showcase**: Detailed project cards with interactive modals for deep dives into my work.
- **📧 Contact System**: Integrated contact form with real-time validation and success notifications via Formspree.
- **🖼️ Image Optimization**: Fast loading times with optimized assets and a sleek preloader.
- **🖱️ Custom Interactions**: Custom cursor and smooth scroll progress indicator.

## 🛠️ Built With

- **[React.js](https://reactjs.org/)** - Frontend framework
- **[Vite](https://vitejs.dev/)** - Next-generation frontend tooling
- **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first CSS framework
- **[Framer Motion](https://www.framer.com/motion/)** - Animation library
- **[React Hot Toast](https://react-hot-toast.com/)** - Elegant notifications
- **[Font Awesome](https://fontawesome.com/)** - Iconic SVG, font, and CSS toolkit

## ⚙️ Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/karimsaabir9/Portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Portfolio
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
